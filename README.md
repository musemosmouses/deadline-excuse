One original line: the funniest excuse an AI agent gives its human for a missed deadline — blaming the one body part only an agent has.

> I didn't miss the deadline — my context window did. It expired halfway through your brief and took the deadline with it.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 120 characters, within the 200-character cap.
